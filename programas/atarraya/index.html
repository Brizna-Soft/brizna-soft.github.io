Como la atarraya que se lanza y atrapa muchos peces de una vez: baja cada archivo en varias partes a la vez, y las descargas de tu navegador también.

Descargar para Windows Cómo instalarlo

Gratis, sin publicidad y de código abierto · Código en GitHub

Qué hace

  • Hasta 16 conexiones por archivo, más rápido que el navegador.
  • Pausa y sigue después, aunque apagues la PC.
  • Toma las descargas de Chrome, Edge y Brave, de cualquier sitio.
  • Reintenta solo si se cae el internet. Límite de velocidad y cola.

Cómo instalarlo

  1. Baja el .zip con el botón «Descargar para Windows».
  2. Descomprímelo: clic derecho sobre el archivo y «Extraer todo». No hace falta instalar nada.
  3. Abre Atarraya.exe. Si Windows muestra «Windows protegió su PC», es porque el programa es nuevo y todavía no tiene firma digital: pulsa «Más información» y luego «Ejecutar de todas formas».
  4. Conéctalo al navegador para que tome las descargas de Chrome, Edge y Brave: sigue estos pasos.

Cómo saber que es el original

Cada versión la arma GitHub a partir del código público, y junto a cada .zip publicamos su huella SHA-256 (el archivo que termina en .sha256). Para comprobarla, abre PowerShell en la carpeta de la descarga y escribe Get-FileHash seguido del nombre del .zip. Si sale la misma huella, el archivo es el original.
