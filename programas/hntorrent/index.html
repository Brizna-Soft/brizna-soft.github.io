HNTorrent: BitTorrent liviano y en español.

Un cliente de BitTorrent liviano y fácil de usar, para bajar archivos sin anuncios ni programas extra.

Descargar para Windows Cómo instalarlo

Gratis, sin publicidad y de código abierto · Código en GitHub

Qué hace

  • Gratis y sin publicidad.
  • No hace falta instalarlo: se descomprime y se abre.
  • Se actualiza solo, y cada actualización va firmada.
  • Si prefieres, en Preferencias apagas la búsqueda de versiones nuevas al abrir.
  • En español, con modo claro y oscuro.

Cómo instalarlo

  1. Baja el .zip con el botón «Descargar para Windows».
  2. Descomprímelo: clic derecho sobre el archivo y «Extraer todo». No hace falta instalar nada.
  3. Abre HNTorrent.exe. Si Windows muestra «Windows protegió su PC», es porque el programa es nuevo y todavía no tiene firma digital: pulsa «Más información» y luego «Ejecutar de todas formas».
  4. Si no abre, instala el Visual C++ de Microsoft y vuelve a abrirlo.

Cómo saber que es el original

Cada versión la arma GitHub a partir del código público. Sus huellas SHA-256 están en el archivo SHA256SUMS.txt de cada versión. Para comprobarla, abre PowerShell en la carpeta de la descarga y escribe Get-FileHash seguido del nombre del .zip. Además, HNTorrent comprueba la firma de cada actualización antes de instalarla.
