Privacidad

En corto: no recogemos tus datos. Ni esta página ni nuestros programas mandan información sobre ti a Brizna Soft.

Esta página

  • No usa cookies, ni estadísticas, ni publicidad, ni botones de redes sociales.
  • La aloja GitHub Pages. Como cualquier servidor, GitHub puede registrar tu dirección IP por seguridad; eso lo cubre la declaración de privacidad de GitHub.
  • Para mostrar el número de la última versión de cada programa, tu navegador le pregunta a la API pública de GitHub (api.github.com).

Nuestros programas

  • No tienen publicidad, no mandan estadísticas y no tienen «telemetría».
  • Solo se conectan a internet para lo que tú les pides: bajar un archivo, buscar una actualización o abrir una página.
  • HNTorrent revisa en GitHub si hay una versión nueva, y cada versión va firmada.
  • Atarraya recibe del navegador las cookies del sitio de cada descarga, solo dentro de tu PC, para que funcionen las descargas que piden sesión iniciada. No las guarda cuando termina y nunca las manda a otro lado.
  • El código de todos está en GitHub, para que cualquiera lo revise.

Donaciones

Las donaciones pasan por PayPal. Tus datos de pago los maneja PayPal; nosotros solo vemos lo que PayPal muestra de cada donación (por ejemplo, el nombre y el monto).

Comentarios y reportes

Los comentarios y reportes se escriben en GitHub, con tu cuenta de GitHub, y son públicos. No pongas ahí contraseñas ni datos personales.

Los comentarios de la portada se muestran con giscus, un proyecto libre que pone las discusiones de GitHub dentro de la página. Según su política de privacidad, no usa cookies ni recoge datos. Si entras con GitHub para comentar, guarda en tu navegador un permiso cifrado para que no tengas que volver a entrar.
