# brizna-soft.github.io

Página de **Brizna Soft**: programas y mods gratis, sin publicidad.

Se ve en https://brizna-soft.github.io. Es una página estática (HTML, CSS y un poco de JavaScript),
publicada con GitHub Pages desde la rama `main`.

- `index.html`: la página.
- `estilos.css`: el diseño (modo claro y oscuro, computadora y celular).
- `app.js`: pone la última versión de HNTorrent y el enlace directo a su descarga.
- `img/`: logos, la captura de HNTorrent y la imagen para compartir el enlace.
