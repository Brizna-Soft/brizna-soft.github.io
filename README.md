# brizna-soft.github.io

Página de **Brizna Soft**: los programas básicos que todos necesitamos, gratis, sin publicidad, sin virus y sin
recoger datos.

Se ve en https://brizna-soft.github.io. Es una página estática (HTML, CSS y un poco de JavaScript), publicada con
GitHub Pages desde la rama `main`. No usa cookies ni estadísticas.

## Archivos

- `index.html`: la página principal.
- `privacidad.html`: qué datos guardamos (ninguno).
- `mods/`: la página de cada mod.
- `estilos.css`: el diseño, con modo claro y oscuro, para computadora y celular.
- `app.js`: pone la última versión de cada programa y el enlace directo a su descarga, con la API pública de
  GitHub.
- `img/`: los logos, las capturas y la imagen que se ve al compartir el enlace.
- `.github/workflows/moderar.yml` y `.github/moderacion/`: el filtro que oculta los comentarios con insultos o
  spam en las discusiones.

## Comentarios y reportes

- **Comentarios y preguntas:** en las
  [discusiones](https://github.com/Brizna-Soft/brizna-soft.github.io/discussions).
- **Fallas de un programa:** en su propio repositorio, con «Reportar un problema».
